# Simple Chatbot Client

A lightweight Python module to send messages to an external LLM API service and get structured responses back with built-in error handling.

I used groq api for this project. you can find other free model to use here: **https://console.groq.com/docs/api-reference**

## Features
* **Simplified Requests:** Wraps complex HTTP payload structures into a simple python function call.
* **Resilient Network Handling:** Catches timeouts and connection dropouts cleanly using custom exceptions.
* **Structured Outputs:** Automatically parses the raw API response down to just the essential data fields you care about.

## Setup & Configuration

1. **Install dependencies:**
   Make sure you have `httpx` installed in your environment:
   ```bash
   pip install httpx
   pip install dotenv  (to load your env file and access your secret data)
   ```

2. **Configure your environment:**
   This module expects a `config.py` file in the same directory containing your API credentials:
   ```python
   # config.py
   API_KEY = "your-api-key-here"
   API_URL = "https://api.groq.com/openai/v1/chat/completions"
   MODEL_NAME = "openai/gpt-oss-safeguard-20b"
   ```

##  Usage Example

You can import and use the `send_message` function directly inside any of your other Python files:

```python
from your_file_name import send_message
from errors import APIError

try:
    # Send a prompt directly as a string
    answer = send_message("Why is the color of atmosphere blue?")
    
    # Access the clean structured data
    print("Response Content:", answer["content"])
    print("Generated By Model:", answer["model"])

except APIError as e:
    # APIError is class imported from chat.errors.py that can be raise to show your errors
    print(f"An error occurred: {e}")
```
